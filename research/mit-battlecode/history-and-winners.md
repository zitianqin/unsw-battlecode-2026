# MIT Battlecode: history and winners

Sources: winners, game names and blurbs come from https://battlecode.org/past.html (fetched 2026-09-23). Placements for 2023–2026 were checked against the final-tournament brackets in the Battlecode API (`https://api.battlecode.org/api/compete/<episode>/match/tournament/?tournament_id=<episode>final`). In those double-elimination brackets, "Round 5 (Winners)" is the grand final and the "Round 4 (Losers Major)" loser finishes 3rd. For 2025 Java a "Round 6" bracket reset also exists. The API has no bc22 data (it returns 404), so 2022 and earlier finalists come only from postmortem self-reports and are marked as such.

Mechanics tagged *[pm]* come from postmortems (see postmortems.md). Mechanics tagged *[mem]* are from memory and are **UNVERIFIED**.

## Recurring format (verified for 2023–2026 from API tournament lists)
- The game is revealed in early January. Over about 4 weeks there are Sprint 1 (about day 7), Sprint 2 (about day 14), US/International Qualifiers (about day 20), and the Final in early February. Sprints are single elimination; qualifiers and finals are double elimination with best-of-5 map matches.
- Between tournaments a ranked ladder runs, with Elo-style ratings and unranked scrimmages you can request against any team.
- Languages: Java only (bytecode-limited, usually about 7.5k–20k bytecode per unit per turn). 2019 used JavaScript/Python (about 10k "instructions"). 2025 added an experimental Python track with a separate bracket. 2026 is Java 21.
- The dev team changes game balance between tournaments ("spec changes"), so the meta resets roughly weekly.

## Earlier years, briefly (all from past.html)
- 2013: macro/economy emphasis, destroy the other team. Winner **Teh Nubs**.
- 2012: build a chain of power nodes to the enemy base. Winner **fun gamers**, which included Cory Li (author of a well-known bytecode-optimisation guide, cited in the XSquare guide).
- 2011: robots with modular components. Winner **Gunface**.
- 2010: points from the convex hull of contiguous buildings. Winner **My Archon Died BellmanFording the Stream**.
- 2009: mine deposits for points. Winner **gtg ice skating lessons**. The same core members as the 2010 winners, so repeat winners happen.
- 2008: capture towers. Winner **In Memory of James Albrecht** (it included Yufei Zhao).
- 2007: destroy archons or out-produce. Winner **My Other Programming Language is Scheme**.
- 2006: King of the Hill. 2005: capture the flag ("RoboCraft"). 2003: kill the queen. 2001–2002: little is known.

## Patterns across the history (inference, with evidence)
1. **Solo and small veteran teams win often.** Greg McGlynn won 2014, 2015 and 2016 (the last with a partner). XSquare won 2020 solo, and wololo (Isaac Liao) won 2022 solo. Veterans reuse code, and the Granberg/Lindholm/Wiman core won 2017 and 2018. Source: past.html winner lists.
2. **Winners are usually not dominant in every game.** 2025: the winner lost the winners' final 2–3 and came back through the reset. 2021: Baby Ducks came from the losers' bracket. 2026: the grand final was 3–2. 2023: the grand final was 3–2. Robustness across maps, rather than a single dominant strategy, decides the final.
3. **The meta shifts every year, but the primitives do not.** Every game needs pathfinding under a compute cap, communication through a narrow channel, local micro (fight/flee), and macro (economy vs aggression). See techniques.md.
4. **Community artefacts:** the battlecode-archive GitHub org (https://github.com/battlecode-archive) holds source for dozens of 2022–2025 teams (for example 2025-Just-Woke-Up, 2024-Gone-Sharkin, 2023-Producing-Perfection, 2022-wololo). camel_case (jmerle) publishes statistics sites for 2023 and 2024 (https://jmerle.github.io/battlecode-2024-statistics/).
